# Beyond Gut Feel: Empirical Evidence That Machine Learning Outperforms Developer Intuition in Observability Decisions

Replication package for a two-part empirical study comparing rule-based heuristics against machine learning for observability decisions.

## Structure

```
beyond-gut-feel/
├── paper.md                           # Full research paper (Sections 1-7)
├── requirements.txt                   # Python dependencies
├── notebooks/
│   ├── part_a/                        # KPI Anomaly Detection
│   │   ├── 01_data_exploration.ipynb  # Dataset download & EDA
│   │   ├── 02_baseline_and_features.ipynb  # Feature engineering, threshold baseline, pooled ML
│   │   ├── 03_per_kpi_models.ipynb    # Per-KPI models, ablation, feature importance
│   │   └── 04_shap_analysis.ipynb     # SHAP explainability & publication figures
│   └── part_b/                        # Log-Level Classification
│       ├── 01_dataset_mining.ipynb    # Mine 15 Node.js/TS repos -> labeled dataset
│       ├── 02_classification.ipynb    # Baselines, CV, cross-project eval, error analysis
│       └── 03_ablation.ipynb          # 5-condition feature ablation study
├── figures/                           # Generated by notebooks (gitignored)
└── data/                              # Generated datasets (gitignored)
```

## Reproduction

### Prerequisites

- Python 3.10+ (or Google Colab)
- ~4 GB disk for cloned repositories (Part B)
- ~30 min total runtime on Colab GPU

### Setup

```bash
pip install -r requirements.txt
```

### Run Order

Notebooks must be run in order within each part. Part A and Part B are independent.

**Part A - KPI Anomaly Detection:**

| # | Notebook | Inputs | Outputs | Time |
|---|----------|--------|---------|------|
| 1 | `01_data_exploration.ipynb` | Downloads AIOps 2018 dataset | EDA plots | ~2 min |
| 2 | `02_baseline_and_features.ipynb` | AIOps 2018 dataset | Threshold baseline, pooled IF/RF models | ~5 min |
| 3 | `03_per_kpi_models.ipynb` | AIOps 2018 dataset | Per-KPI models, ablation curve, feature heatmap | ~8 min |
| 4 | `04_shap_analysis.ipynb` | AIOps 2018 dataset | SHAP plots, publication figures | ~10 min |

**Part B - Log-Level Classification:**

| # | Notebook | Inputs | Outputs | Time |
|---|----------|--------|---------|------|
| 1 | `01_dataset_mining.ipynb` | Clones 15 GitHub repos | `data/log_level_dataset.csv` | ~5 min |
| 2 | `02_classification.ipynb` | `data/log_level_dataset.csv` | CV results, confusion matrix, cross-project eval | ~8 min |
| 3 | `03_ablation.ipynb` | `data/log_level_dataset.csv` | 5-condition ablation, per-class breakdown | ~5 min |

## Key Results

- **Part A:** Per-KPI ML achieves median F1 = 0.41 vs 0.18 for static threshold (μ ± 3σ). 53% of features removable without performance loss.
- **Part B:** XGBoost achieves cross-project macro F1 = 0.89 using code context only (vs 0.37 keyword heuristic). Removing message TF-IDF drops F1 by only 0.005.
